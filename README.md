# Json_lib

c++ json library 实现，参考 https://github.com/miloyip/json-tutorial/

## 实现目标

- [x] JSON 布尔类型的解析
- [ ] JSON 数字解析
- [ ] JSON 一般字符串解析
- [ ] JSON Unicode字符串解析
- [ ] JSON 数组解析
- [ ] JSON Object 解析
- [ ] JSON 生成器
- [ ] JSON Array／Object 的访问及修改
- [ ] nativejson-benchmark 测试


## 代码架构

- [src](./src/) : 源代码
- [include](./include/) : 头文件
- [test](./test) : 测试文件
- [notes](./notes) : 实现思路
